# Implementation Plan: Постановка пальцев

**Branch**: `main` | **Date**: 2026-10-17 | **Spec**: [spec.md](spec.md)
**Input**: `specs/004-fingers/spec.md`, бриф `.planning/FINGERS-BRIEF.md`, стенд 005 (`.planning/UI-STANDS.md`)

## Summary

Тренажёр выходит из настроек: одно окно Ghbdtn с переключателем «Утилита / Тренажёр». В тренажёре новый раздел
«Постановка» — 15 уровней (русские буквы, английские ряды, знаки, Shift, Backspace), занятие 5 минут словами только
из открытых букв, постоянная клавиатура с цветами пальцев и руки по бокам. Буква освоена при ≥ 95 % и ≥ 100 зн/мин
в двух разных днях; уровень открывается целиком, когда освоены все открытые буквы. Разминка 003 закрыта до уровня 12.

## Подход по фазам

1. **Ядро `fingers.rs`** — `LEVELS` (15), клавиша → палец, состояние клавиши (в работе / освоена), день прохождения
   порога, откат, открытие уровня, текущий уровень, «разминка открыта» (уровень 12 пройден); материал: слова из
   `*.freq`, все буквы открыты, вес «в работе» и новых ×3, повторы на бедных уровнях, знаки/заглавные/Backspace по
   уровням 13–15 (research R2–R5). Юнит-тесты на синтетике.
2. **Оболочка** — `fingers.json` (атомарная запись как в 003), команды `fingers_state/material/finish/reset`; серия
   и «сегодня» считают завершённые занятия постановки; напоминание до уровня 12 зовёт на постановку («5 минут
   постановки: уровень N»).
3. **Хаб** — одно окно `settings` с капсулой «Утилита / Тренажёр» (стенд 005, Место C); последняя вкладка в
   `localStorage`, `open_trainer` открывает окно на «Тренажёре» (`#trainer` / событие `hub-tab`); окно `trainer`
   убрано; меню трея: «Открыть Ghbdtn» вместо «Настройки», строка «Постановка · Уровень N» до уровня 12, затем
   «Разминка»; группа «Тренажёр» из «Основного» → раздел «Настройки» тренажёра.
4. **Раздел «Постановка»** — карта-дорожка с туманом закрытых, экран уровня (плитки букв, клавиатура, руки),
   занятие (лента 003, клавиатура и руки по бокам, подсветка клавиши и пальца, режимы Shift и Backspace), итог
   строками по буквам; «Разминка» закрыта с полосой из 12 уровней. Цвета — «Две руки».
5. **Приёмка** — quickstart, `pnpm check`, `pnpm build`, корпус; адверсарий после каждой фазы; релиз — с согласия.
