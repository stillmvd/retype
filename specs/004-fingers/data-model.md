# Data Model: Постановка пальцев (004)

## Level (ядро, константа)

| Поле | Тип | Пример |
|---|---|---|
| `n` | u8 1–15 | 4 |
| `name` | &str | «Указательные вниз» |
| `keys` | &str | `мить`; 14 — `⇧`, 15 — `⌫` |
| `lang` | ru / en | ru |

## fingers.json

```json
{ "level": 4,
  "keys": { "ф": { "days": ["2026-10-15", "2026-10-16"], "mastered": true, "acc": 0.98, "cpm": 131 },
            "м": { "days": ["2026-10-17"], "mastered": false, "acc": 0.97, "cpm": 109 } },
  "sessions": [ { "date": "2026-10-17", "seconds": 300, "done": true, "level": 4, "accuracy": 0.95, "cpm": 103 } ],
  "intro": 4 }
```

- `level` — наибольший открытый уровень (1 при первом запуске). Открытые клавиши — все клавиши уровней 1..level.
- `keys` — только клавиши, по которым были занятия; нет записи — «в работе», дней 0.
- `days` — уникальные даты, когда порог пройден (хранятся последние 2).
- `intro` — последний уровень, экран которого показан после открытия (для «Открыт уровень N» перед занятием).
- `sessions` — итоги занятий (для серии и «Прогресса»), дни старше 365 удаляются. Набранного текста нет.

## FingerSession (окно → оболочка)

```ts
type FingerSession = { seconds: number; done: boolean; accuracy: number; cpm: number;
                       keys: Record<string, { n: number; miss: number; ms: number }> };
```

- `n` — верные нажатия клавиши, `miss` — позиции с промахом, `ms` — сумма мс до верного нажатия.

## Состояния клавиши

```
закрыта ──(открыт её уровень)──▶ в работе
в работе ──(2 разных дня: ≥ 10 нажатий, ≥ 95 %, ≥ 100 зн/мин)──▶ освоена
освоена ──(завершённое занятие: ≥ 10 нажатий и ниже порога)──▶ в работе (остаётся 1 день)
```

## Уровень

```
закрыт ──(все открытые клавиши освоены после завершённого занятия)──▶ текущий ──(следующий открыт)──▶ пройден
```

Разминка 003 открыта при `level ≥ 13`.
