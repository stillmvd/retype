# Quickstart: проверка тренажёра (003)

## Автоматически

- `pnpm check` — юнит-тесты `stats.rs` (выравнивание стёрто → набрано, пары, сброс), `trainer.rs` (слабые и
  побеждённые пары, смесь материала, фильтр слов журнала), конфиг `trainer`.
- Корпус — без изменений (тренажёр не трогает решения).
- Стенд `rivals` (с согласия) — SC-004: задержка исправления со включённым `trainer.count` не хуже текущей + 1 мс.

## Вручную

1. Меню трея → «Тренажёр»: окно открывается ≤ 1 с; первый запуск предлагает «Считать ошибки печати».
2. Разминка: неверная клавиша не печатается, курсор стоит; слово с ошибкой возвращается; русское слово в раскладке en
   даёт подсказку сменить раскладку, без ошибки; через 3 мин — итог (точность, скорость, пары).
3. Пока окно тренажёра в фокусе, Ghbdtn ничего не исправляет (набрать «ghbdtn » в поле — не меняется).
4. Счётчики: включить, в Блокноте набрать «пииет», стереть «ии», набрать «ри», пробел; через минуту в `typing.json`
   +1 слово, +1 промах, пара `и>р`; поиск по `%APPDATA%\Ghbdtn` слова «привет» вне `log\` — пусто (SC-005).
5. Пароль / «не трогать» программу / полный экран — счётчики не меняются.
6. Напоминание: «Показать пример» в настройках — уведомление сразу; удалить `reminded` из `trainer.json`, Win+L на
   ≥ 30 с и разблокировать (или 10 мин без ввода и нажать клавишу) —
   уведомление «Размяться»; кнопка открывает тренажёр; повторно в тот же день — нет.
7. Прогресс: подложить `typing.json` за 3 недели — линия по неделям; пара без промахов 7 дней — в «побеждённых».
8. «Стереть данные тренажёра» — оба файла удалены, прогресс пуст.
