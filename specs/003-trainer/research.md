# Research: Тренажёр печати (003)

## R1. Где считать ошибки реальной печати

- **Decision**: в рабочем потоке ядра (`Worker::key` / `back` / `finish`), чистый модуль `core/src/stats.rs`
  (без Win32): по событиям «буква / Backspace / конец слова / сброс» выравнивает стёртые и заново набранные буквы и
  копит дневной итог `Tally` (слов, промахов, пары, нажатия по буквам). `Tally` лежит в `Arc<Mutex<…>>`, общий с
  оболочкой; оболочка раз в минуту и при выходе сливает его в файл.
- **Rationale**: хук уже собирает слово в `Worker` (буфер `word`, `edit`); колбэк хука не меняется (конституция II).
  Слова в канал событий не уходят — наружу только числа.
- **Alternatives**: событие с буквами слова в `CoreEvent` (слово уходит в другой поток — лишняя копия текста);
  отдельный хук (второй LL-хук — задержка всего ввода).

## R2. Выравнивание «стёрто → набрано»

- **Decision**: внутри слова Backspace снимает букву в стек стёртых; следующие набранные буквы сопоставляются со
  стёртыми по позиции. Пара пишется, если число стёртых и набранных совпало (замена) и буквы разные. Иначе — только
  промах без пары. Стёртая серия, после которой слово кончилось без новых букв, — не промах (человек передумал).
  Исправление опечатки ядром (`Acted { kind: Typo }`) — +1 промах; пара — если исправление — одна замена буквы той же
  длины. Слово не в той раскладке и его исправление — не промах. Сброс ввода (клик, смена окна, Ctrl+…) теряет
  незавершённую серию.
- **Rationale**: соответствует уточнению «промах = стёрто-заменено руками + опечатка, исправленная Ghbdtn»; неравные
  серии (пропуск, лишняя буква) неоднозначны для пары, но всё равно промах.

## R3. Тишина в окне тренажёра

- **Decision**: `Worker::evaluate` — если окно в фокусе принадлежит своему процессу, статус «молчу» (новая причина
  `Own`, в журнал не пишется, в меню трея не показывается). Работает и для окна настроек.
- **Rationale**: FR-006; проще и надёжнее, чем список процессов (exe может называться иначе в dev).

## R4. Материал разминки

- **Decision**: чистый модуль `core/src/trainer.rs`:
  - частые слова — первые 5000 строк `ru.freq`/`en.freq` (уже встроены `include_str!`, разбор < 10 мс, словари
    целиком не грузятся — их 1,6 с не укладываются в SC-001);
  - слова под слабые пары — частые слова, где верная буква пары стоит рядом с ошибочной или встречается дважды;
    вес — доля промахов пары;
  - реальные опечатки — верные формы из журнала (`acted` kind=typo → `result`, `retyped` без исправления → `after`)
    за 30 дней, только буквы и дефис, только слова из частотного списка (FR-010: ники, пароли, адреса отсекаются);
  - фразы — короткие предложения Tatoeba (ru, en; 20–80 знаков, только буквы своего алфавита, пробел и `, . ? ! - :`),
    по ~2000 на язык, файлы `core/data/{ru,en}.phrases`, лицензия CC BY 2.0 FR в «О программе».
  - смесь: 40 % слабые пары, 25 % опечатки из журнала, 35 % фразы; без своих данных — частые слова с общими трудными
    сочетаниями и фразы. Доля ru/en — по счётчикам слов за 14 дней (без счётчиков — 70/30).
  - упражнение — поток строк ~на 6 минут печати; таймер обрезает.
- **Rationale**: без сети, без новых тяжёлых словарей; фразы из настоящих предложений лучше склеек биграмм.
- **Alternatives**: склейка фраз из биграмм Leipzig (неестественно); Leipzig предложения (лицензия неясна для
  распространения).

## R5. Слабые и побеждённые пары

- **Decision**: окно 14 дней; пара слабая, если `промахи_пары / нажатия_верной ≥ 2 %` и нажатий ≥ 50 (реальная печать
  + тренажёр; без счётчиков — только тренажёр, порог нажатий 20). Побеждена — 7 подряд дней с нажатиями верной
  буквы ≥ 50 (реальная печать) и без промахов по паре. Новые промахи ≥ порога — снова слабая. Пороги — константы в
  `trainer.rs`, подбираются тестом на синтетике и данными пользователя после недели.
- **Rationale**: уточнения 2026-10-17; без нажатий «неделя без промахов» ничего не значит.

## R6. Палец для клавиши

- **Decision**: таблица в UI по физическому коду клавиши (`KeyboardEvent.code`, одинаков для ЙЦУКЕН и QWERTY):
  стандартная схема десяти пальцев. Показывается только для верной буквы слабых пар.

## R7. Раскладка в тренажёре

- **Decision**: окно сравнивает `KeyboardEvent.key` с ожидаемой буквой; если нажатая буква из другого алфавита, а
  `code` даёт ожидаемую букву в нужной раскладке — подсказка «Переключи раскладку», не ошибка и курсор стоит.
  Пробел, цифры и знаки сравниваются по `key`.

## R8. Напоминание

- **Decision**: уведомление Windows через WinRT `ToastNotificationManager` (`windows` features `UI_Notifications`,
  `Data_Xml_Dom`) с кнопкой «Размяться»; событие `Activated` в своём процессе открывает тренажёр (Ghbdtn всегда
  запущен — COM-активатор не нужен). AUMID — идентификатор приложения из ярлыка установщика; в dev — свой
  `SetCurrentProcessExplicitAppUserModelID`. Момент: поток оболочки раз в 30 с смотрит `GetLastInputInfo`; первый
  ввод после простоя ≥ 10 мин, если за день ≥ 100 слов (счёт слов в памяти, даже при выключенных счётчиках — на
  диск не пишется), разминки сегодня не было, напоминания сегодня не было, не полный экран → уведомление; дата
  последнего напоминания — в файле тренажёра.
- **Rationale**: уточнение «уведомление Windows»; показ в момент возвращения, а не в начале паузы — человек его
  увидит.
- **Fallback**: если `Activated` не приходит в установленной сборке — уведомление без кнопки, клик по телу
  обрабатывается тем же событием; проверить в T-приёмке.

## R9. Хранение

- **Decision**: `%APPDATA%\Ghbdtn\typing.json` — счётчики по дням (только при включённом тумблере);
  `%APPDATA%\Ghbdtn\trainer.json` — разминки, слабые/побеждённые пары, дата напоминания, длина (3/5). Удаление дней
  старше 365. Кнопка «Стереть» удаляет оба файла (история разминок — по отдельному подтверждению не нужна: одна
  кнопка «Стереть данные тренажёра»).
- **Rationale**: уточнение «год»; JSON — как журнал, без новых зависимостей.

## R10. Настройки

- **Decision**: `Config.trainer { count: bool = false, remind: bool = true, minutes: u8 = 3 }`. Тумблеры «Считать
  ошибки печати» и «Напоминать о разминке» — в настройках (раздел «Тренажёр»); первый запуск тренажёра предлагает
  включить счёт.
