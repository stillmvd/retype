# Data Model: Тренажёр печати (003)

## Config.trainer (в `config.toml`)

| Поле | Тип | По умолчанию | Правило |
|---|---|---|---|
| `count` | bool | false | вкл. — ядро копит `Tally`, оболочка пишет `typing.json` |
| `remind` | bool | true | напоминание раз в день |
| `minutes` | u8 | 3 | только 3 или 5 |

## Tally (ядро, в памяти; день)

- `words: u32` — завершённые слова (буквы/дефис, ≥ 1 буквы), только при статусе `Working`.
- `misses: u32` — промахи (R2).
- `pairs: Map<(wrong: char, right: char), u32>` — строчные буквы.
- `presses: Map<char, u32>` — нажатия букв (строчные), для порогов.
- Сбрасывается после слива в файл. Слова и порядок нажатий не хранятся.

## typing.json

```json
{ "days": { "2026-10-17": { "words": 1520, "misses": 41,
  "pairs": { "р>о": 6, "б>ю": 3 }, "presses": { "о": 900, "ю": 40 } } } }
```

- Ключ пары `"<ошибочная>><верная>"`. Дни старше 365 удаляются при записи.

## trainer.json

```json
{ "sessions": [ { "date": "2026-10-17", "seconds": 180, "done": true, "accuracy": 0.96, "cpm": 210,
                  "pairs": { "р>о": 2 }, "presses": { "о": 60 } } ],
  "weak": { "р>о": "2026-10-03" },
  "won": { "б>ю": "2026-10-10" },
  "reminded": "2026-10-17" }
```

- `sessions` — разминки; `done` = таймер дошёл до конца. Серия считается по датам с `done`.
- `weak` — слабые пары и дата, с которой пара слабая: пара остаётся тут до победы, даже если доля за 14 дней упала.
- `won` — побеждённые пары и дата победы; пара удаляется отсюда, когда снова слабая.
- Дни старше 365 удаляются.

## Состояния пары

```
нет данных ──(доля ≥ 2 %, нажатий ≥ 50 за 14 дн.)──▶ слабая
слабая ──(7 дней реальной печати: нажатий верной ≥ 50/день, промахов 0)──▶ побеждена
побеждена ──(снова доля ≥ 2 % за 14 дн.)──▶ слабая
```

## Материал (в памяти окна)

- `Item { text: String, lang: ru|en, kind: weak|journal|phrase|common, focus: Vec<char> }` — `focus` — буквы, у
  которых показывать палец. На диск не пишется.
